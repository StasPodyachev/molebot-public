# FE-16 — Dashboard: отдельный роут + React Router

## Контекст
Сейчас и лендинг, и дашборд находятся в одном файле `App.tsx`.
Dashboard-блок показывается при `authenticated && userAddress`.
Нет роутинга, нет отдельного URL `/dashboard/:tokenId`.

## Acceptance criteria
- [ ] `/` — лендинг без дашборда
- [ ] `/dashboard/:tokenId` — дашборд (только для авторизованных)
- [ ] После минта пользователь попадает на `/dashboard/<tokenId>`
- [ ] Все существующие функции (mint, chat, balance) работают после рефакторинга
- [ ] `npm run build` проходит без ошибок

## Затронутые файлы
- `frontend/src/App.tsx` — сократить до Routes
- `frontend/src/main.tsx` — добавить BrowserRouter
- `frontend/src/pages/LandingPage.tsx` — создать
- `frontend/src/pages/DashboardPage.tsx` — создать
- `frontend/src/pages/RequireAuth.tsx` — создать (auth guard)
- `frontend/package.json` — добавить react-router-dom

## План
1. Установить `react-router-dom`
2. Создать `LandingPage.tsx` — перенести landing-код из App.tsx
3. Создать `DashboardPage.tsx` — перенести dashboard-блок
4. В App.tsx оставить `<Routes>` с двумя роутами
5. Добавить BrowserRouter в main.tsx
6. Создать RequireAuth guard
