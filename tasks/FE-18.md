# FE-18 — ChatPanel: передать реальный tokenId

## Контекст
В `App.tsx` определён `const [nftId, setNftId]` — setNftId **никогда не вызывается**,
поэтому ChatPanel всегда получает `tokenId={nftId ?? ''}`, то есть пустую строку.
Чат не работает даже после минта крота.

## Acceptance criteria
- [ ] После загрузки NFT (useMoleNFT) ChatPanel получает реальный tokenId
- [ ] При пустом nft ChatPanel показывает заглушку, не пытается делать EIP-712
- [ ] `const [nftId, setNftId]` убран из App.tsx, передача идёт через `nft?.tokenId`

## Затронутые файлы
- `frontend/src/App.tsx` — строка `const [nftId, setNftId]` и место вызова
- `frontend/components/ChatPanel.tsx` — проверка tokenId перед EIP-712

## План
1. В App.tsx убрать `const [nftId, setNftId]`, передавать `tokenId={nft?.tokenId ?? ''}`
2. В ChatPanel: если tokenId пустой/0 — не показывать окно чата, выводить "Крот ещё не создан"
3. Проверить сборку: `npm run build` без ошибок
