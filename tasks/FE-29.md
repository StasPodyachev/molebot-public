# FE-29 — Dashboard: стратегии торговли

## Контекст
Сейчас у крота есть только mood и уровень, но нет UI для стратегий,
которыми он торгует. Пользователь не может:
- Посмотреть текущую стратегию крота
- Выбрать/сменить стратегию
- Видеть сигналы (BUY/SELL/HOLD)

## Что входит
1. **Блок стратегий** на Dashboard под NFT-карточкой
2. **Список стратегий** (select/tabs): Консервативная, Агрессивная, DCA, HODL
3. **Индикатор активной стратегии** — подсветка, название, краткое описание
4. **Сигнал** — BUY / SELL / HOLD со стрелкой и цветом
5. **Кнопка "Сменить стратегию"** — подтверждение через Privy (EIP-712 опционально)
6. **GET /api/strategy** — текущая стратегия и сигнал (backend)
7. **POST /api/strategy/set** — смена стратегии (backend, mock‑режим допустим)

## Acceptance criteria
- [ ] На Dashboard виден блок "Стратегия": название + сигнал
- [ ] Можно переключить стратегию (через попап)
- [ ] Сигнал обновляется (хотя бы при перезагрузке)
- [ ] npm run build проходит, линтер не падает

## Затронутые файлы
- `frontend/src/pages/DashboardPage.tsx` — добавить блок стратегий
- `frontend/components/StrategyPanel.tsx` — создать
