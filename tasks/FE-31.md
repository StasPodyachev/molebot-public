# FE-31 — Dashboard: статистика крота

## Контекст
Сейчас Dashboard показывает только tokenId и MNT-баланс.
Нет торговой статистики, хотя она критична для демо-презентации.

## Что входит
1. **Stats block** под NFT-карточкой (или в TradePanel):
   - Total trades
   - Win rate (%)
   - Current PnL (+ X USDC)
   - Best / worst trade
   - Daily PnL (если есть данные)
2. **GET /api/trade/stats** — статистика с backend'а
3. **Mood → stats correlation** — если mood нейтральный, но PnL отличный —
   это фича для демо (AI-агент не зависит от рынка)
