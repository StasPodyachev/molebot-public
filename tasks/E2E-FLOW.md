# E2E Flow Checklist — Reviewer

Перед мержем любого PR, связанного с mint/chat/trade, Reviewer
проверяет полный цикл:

## 1. Mint NFT
- [ ] Кнопка Mint отображается для нового кошелька
- [ ] Privy popup показывает транзакцию mint
- [ ] Транзакция проходит (0.05 MNT)
- [ ] После майнинга отображается Molebot #N с данными

## 2. Chat Session
- [ ] Показывается счётчик "осталось N/10"
- [ ] Кнопка "Подписать ещё 10" работает
- [ ] EIP-712 подпись отображается в Privy
- [ ] После подписи счётчик обновляется (10/10)

## 3. Chat Message
- [ ] Поле ввода активно
- [ ] Ввод текста и отправка
- [ ] Ответ от mantle-agent (не пустой, не 502/405)
- [ ] Счётчик уменьшается (9/10)
- [ ] Нет ошибок в console (F12)

## 4. Chat History
- [ ] Сообщения сохраняются
- [ ] Счётчик не сбрасывается при перезагрузке

## 🛑 Если любой пункт красный — PR НЕ МЕРЖИТЬ
