# FE-30 — Dashboard: сделки (Trade Log)

## Контекст
Крот может торговать (Agni plugin, mockMode=true), но нет UI:
- История сделок (date, pair, side, amount, pnl)
- Статус активной позиции (entry price, current price, pnl %)
- Кнопка "Open Trade" / "Close Trade" (mock или real)

## Что входит
1. **TradeLog** — таблица последних N сделок (или заглушка)
2. **Active position** — карточка: entry, current, pnl, duration
3. **Кнопки действий** — Open Trade / Close Trade (POST /api/trade)
4. **Backend handler** — GET /api/trade/history + POST /api/trade/open + POST /api/trade/close
5. **Mock execution** — trade executor симулирует своп (mockMode=true)

## Acceptance criteria
- [ ] Dashboard показывает TradeLog (минимум 1–3 mock сделки)
- [ ] Активная позиция отображается (или "Нет активных сделок")
- [ ] Кнопки Open/Close Trade работают в mock-режиме
- [ ] npm run build проходит
