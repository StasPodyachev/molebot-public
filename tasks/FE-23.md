# FE-23 — Chat: /api/chat не отвечает JSON, падает res.json()

## Контекст
FE-17 подключил реальный MNT-перевод. После подписи транзакции ChatPanel
вызывает `res.json()` на ответ от `/api/chat`, но сервер возвращает пустой
или HTML ответ (404, 502 — backend не развёрнут). JS падает с
`⚠️ Failed to execute 'json' on 'Response': Unexpected end of JSON input`.

## Acceptance criteria
- [ ] Перед `res.json()` проверять `res.ok` и `Content-Type: application/json`
- [ ] Если ответ не JSON — прочитать как текст, показать "Бекенд чата недоступен (HTTP {status})"
- [ ] Если сеть недоступна — показать "Сервис чата временно недоступен"
- [ ] В `console.warn` логировать реальный статус и тело ответа для диагностики
- [ ] `npm run build` проходит

## Затронутые файлы
- `frontend/components/ChatPanel.tsx` — строка 214, обработка res.json()

## План
1. Заменить `res.json()` на: `const text = await res.text(); let data = JSON.parse(text)`
2. Если JSON.parse падает — показать ошибку с HTTP статусом
3. Добавить console.warn('POST /api/chat failed', status, text)

## Notes / лог
- Backend (/api/chat) должен быть развёрнут отдельно — это задача не фронта
- Нужен DeepSeek API ключ от Стаса для LLM Gateway
