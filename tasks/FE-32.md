# FE-32 — RPC Proxy через VPS

## Контекст
Privy embedded wallet шлёт конкурентные RPC-запросы (estimateGas, getNonce,
getGasPrice, eth_call) на `rpc.sepolia.mantle.xyz`. Публичный RPC дропает
429 (Too Many Requests), транзакции не подписываются.

Через браузер идёт 10+ параллельных RPC-вызовов. Даже FallbackProvider
не помогает — Privy использует свой провайдер.

## Решение
Добавить `/rpc` endpoint на Caddy (VPS), который проксирует запросы на
Mantle RPC с единого IP (VPS). Одно steady-соединение вместо 10 из браузера.

### Caddyfile (infra/Caddyfile.mantle)
```
handle /rpc {
    reverse_proxy https://rpc.sepolia.mantle.xyz {
        header_up Host rpc.sepolia.mantle.xyz
        header_up X-Forwarded-For {remote_host}
    }
}
```

### Frontend (mantle-chain.ts)
Поменять RPC URL для Privy chain config:
```
default: { http: ['https://vps.molebot.org/rpc'] }
```

## Acceptance criteria
- [ ] `curl -X POST https://vps.molebot.org/rpc -d '{"method":"eth_blockNumber"}'` возвращает валидный результат
- [ ] После обновления chain config — Privy не дропает 429
- [ ] Mint работает: подписать → отправить → подтверждение
- [ ] EIP-712 подпись для чата тоже работает

## Затронутые файлы
- `infra/Caddyfile.mantle` — добавить handle /rpc
- `frontend/lib/mantle-chain.ts` — rpcUrls.default → vps.molebot.org/rpc
- `/home/x/molebot/infra/Caddyfile` — поверхностная копия (Docker Caddy)

## План
1. Добавить `/rpc` route в Caddyfile.mantle
2. Скопировать на VPS: `sudo cp infra/Caddyfile.mantle /home/x/molebot/infra/Caddyfile`
3. Перезагрузить Docker Caddy: `docker exec infra-caddy-1 caddy reload`
4. В mantle-chain.ts: заменить RPC URL
5. Пересобрать, PR, deploy

## ❌ Не сработало (почему)

### 1. FallbackProvider с обоими RPC
`ethers.FallbackProvider` с `MANTLE_RPC_URLS = [official, drpc]`
**Причина:** dRPC иногда возвращает chainId=1 (mainnet вместо 5003).
ethers детектит несоответствие сети и падает с NETWORK_ERROR.
**Правильное решение:** VPS RPC proxy (единый endpoint).

### 2. Смена Privy chain config на dRPC
`rpcUrls.default.http: ['https://mantle-sepolia.drpc.org']`
**Причина:** dRPC нестабилен — то 500, то chainId mistmatch.
**Правильное решение:** оставить официальный RPC как fallback, но
проксировать через VPS.
