# FE-25 — Chat: EIP-712 подпись не срабатывает

## Контекст
FE-24 добавил session billing: пользователь подписывает EIP-712 → создаётся сессия на 10 сообщений.
Но Privi wallet не показывает окно подписи. После нажатия "Подписать ещё 10" — пропадает кнопка, ничего не происходит.

## Анализ (planner)
Проблема в ChatPanel.tsx строка 162:
```
const wallet = wallets.find(w => w.walletClientType === 'privy');
```
В некоторых версиях @privy-io/react-auth `walletClientType` может быть `'embedded'` или `'privy'`. Фильтр не находит кошелёк → кидает ошибку.

Дополнительно: после `createSession` UI уходит в `signingSession=true` и не показывает индикатор загрузки, кнопка просто пропадает.

## Acceptance criteria
- [ ] Privy/MetaMask показывает окно EIP-712 подписи при нажатии "Подписать ещё 10"
- [ ] После подписи сессия создаётся (POST /api/chat/session ok)
- [ ] UI показывает индикатор загрузки (спиннер) во время подписи
- [ ] Если кошелёк не найден — показать человеческое сообщение, не просто ошибку JS
- [ ] npm run build проходит
