# FE-28 — Chat: apiBase без /api префикса, CORS не проходит

## Контекст
После фикса INFRA-04 (HTTPS через vps.molebot.org) чат всё ещё не работает.
Ошибки в консоли:

```
Access to fetch at 'https://vps.molebot.org/chat/quota?tokenId=1'
No 'Access-Control-Allow-Origin' header

GET https://vps.molebot.org/chat/quota?tokenId=1 404 (Not Found)
```

## Root cause
`apiBase = 'https://vps.molebot.org'` → `${API}/chat/session` = `https://vps.molebot.org/chat/session`
а должно быть `https://vps.molebot.org/api/chat/session` (с `/api` префиксом).

VPS Caddy обрабатывает только `/api/*` → mantle-agent.
Без `/api` попадаем в catch-all → 404 + без CORS-заголовков.

## ❌ Не сработало (почему)

### 1. Прямой HTTP к VPS (`http://178.105.123.110`)
ChatPanel.tsl: `apiBase || 'http://178.105.123.110'`
**Причина:** Mixed Content — браузер блокирует HTTP с HTTPS-страницы.
CSP `connect-src` не обходит этот механизм.
**Правильное решение:** DNS A-запись с Cloudflare Proxy.

### 2. CF Pages _redirects с status 200 для POST
`_redirects: /api/* http://178.105.123.110/api/:splat 200`
**Причина:** CF Pages _redirects (status 200) проксирует только GET/HEAD.
POST запросы получают 405 Method Not Allowed.
**Правильное решение:** прямой HTTPS вызов VPS через DNS.
