# FE-34 — Vault: пополнение баланса крота

## Контекст
Крот не может торговать — у него нет баланса. На Dashboard отображается 
`PnL: +0 USDC`, но нет:
- Баланса vault'а (сколько MNT у крота на торговлю)
- Кнопки "пополнить"
- Отображения транзакций пополнения/вывода

ТЗ: пользователь депозит MNT (или USDC) в vault своего крота,
агент торгует с этого баланса через MoleVault.

## Что уже есть
- **MoleVault.sol** — контракт vault'а (`packages/contracts-evm/contracts/MoleVault.sol`)
  - `deposit(uint256 tokenId)` — native MNT
  - `depositToken(uint256 tokenId, address token, uint256 amount)` — ERC20
  - `withdraw(uint256 tokenId, uint256 amount)` — вывод MNT
- **Деployed:** `0x252F0d506Da5131Bdc469796b273c724AB8Bc6F7` (Mantle Sepolia)
- **ABI в агенте:** `agent/src/plugins/agni/constants.ts` — checkSession, executeSwap, getVaultBalance
- **Agent config:** `infra/.env.mantle` — `MOLE_VAULT_ADDRESS`
- **Trade executor:** `mockMode=true` — vault не используется пока

## Что нужно сделать
### Frontend
1. **VaultBalance.tsx** — компонент отображения баланса vault'а
   - Вызов `getVaultBalance(tokenId, address(0))` → native MNT balance
   - Вызов `getVaultBalance(tokenId, USDC_ADDRESS)` → USDC balance
   - Форматирование: X.XXXX MNT / USDC
2. **DepositButton.tsx** — кнопка "Пополнить"
   - Privy popup → send MNT to vault address
   - Вызов `vault.deposit(tokenId)` с value = сумма
3. **DashboardPage.tsx** — добавить VaultBalance над TradePanel
4. **UserBalance.tsx** — если vault есть баланс, показать "Vault: X MNT"
5. **GET /api/vault/stats** — баланс vault'а для tokenId (бекенд, mock опционально)

### Backend (agent)
6. **vaultRouter.ts** — GET /api/vault/balance?tokenId=...
   - Читает getVaultBalance через RPC
   - Кэширует на 30 сек (чтобы не дудосить RPC)

### Smart Contract (опционально)
7. Проверить, что MoleVault задеплоен корректно.
   Сейчас `eth_call` на `getVaultBalance` ревертится — возможно ABI не совпадает
   или vault требует инициализации.

## Acceptance criteria
- [ ] На Dashboard виден баланс vault'а (MNT)
- [ ] Кнопка "Пополнить" → Privy → tx → баланс обновляется
- [ ] После пополнения PnL показывает не 0
- [ ] npm run build проходит

## План
1. Создать VaultBalance.tsx + DepositButton.tsx
2. Интегрировать в Dashboard
3. Добавить vaultRouter.ts в agent (GET /api/vault/balance)
4. Проверить vault contract ABI (если ревертится — sync с Solidity)

## ❌ Возможные проблемы
- MoleVault `getVaultBalance(uint256,address)` ревертится — проверить ABI
- MoleVault может требовать `onlyNFTOwner` — депозит только от владельца NFT
- vault может не иметь функции `deposit` view — нужно через RPC
