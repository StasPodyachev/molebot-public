# FE-27 — Mint: estimateGas CALL_EXCEPTION

## Контекст
Пользователь нажимает Mint Molebot (0.05 MNT), Privy embedded wallet
вызывает `estimateGas` на контракт, получает ошибку:

```
missing revert data (action="estimateGas", data=null, reason=null,
transaction={ "data": "0x1249c58b", ... },
invocation=null, revert=null, code=CALL_EXCEPTION, version=6.16.0)
```

## Root causes (из диагностики)

### 1. RPC chainId mismatch
При использовании `https://mantle-sepolia.drpc.org` ethers детектил chainId=1
(mainnet) вместо 5003. Это вызывало `NETWORK_ERROR: network changed: 1 => 5003`.

### 2. RPC 429 rate limit
Официальный RPC `rpc.sepolia.mantle.xyz` возвращает 429 при большом
количестве запросов. Privy делает много параллельных RPC вызовов
(estimateGas, getNonce, getGasPrice, eth_call).

### 3. Mixed Content блокирует fix
Попытка обойти CF Pages через прямой вызов VPS по HTTP блокируется
браузером (INFRA-04).
