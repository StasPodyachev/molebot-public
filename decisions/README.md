# decisions/

Append-only журнал архитектурных и операционных решений (ADR-lite).

- Один файл = одно решение: `<YYYY-MM-DD>-<slug>.md`.
- Решения **не переписываются**. Изменил мнение — новый файл, который ссылается на старый (superseded by).
- Сюда же deployer пишет результаты деплоев (адреса, SHA, окружение).

Минимальный формат:
```md
# <YYYY-MM-DD> — <Заголовок>
- Status: accepted | superseded
- Context: почему встал вопрос
- Decision: что решили
- Consequences: последствия / что меняется
```
